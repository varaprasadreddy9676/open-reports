Render an invoice from your application

Your host sends a report definition and authorized data to the Open Reports rendering API.

Host application · Node.js request
const response = await fetch(
  `${OPEN_REPORTS_URL}/api/v1/render`,
  {
    method: "POST",
    headers: {
      "content-type": "application/json",
      "x-api-key": OPEN_REPORTS_API_KEY,
    },
    body: JSON.stringify({
      report: invoiceReportDefinition,
      format: "pdf",
      data: { invoice: authorizedInvoice, items: authorizedLineItems },
    }),
  },
);

const pdfBytes = await response.arrayBuffer();
// Keep the API key in this server-side code.
// Your host can encode pdfBytes as Base64 if needed.
POST http://localhost:4000/api/v1/render · host-owned JSON · PDF

In this example the Open Reports API key is intentionally omitted because local demo authentication is disabled. In production, call from your backend and keep the privileged key there.
