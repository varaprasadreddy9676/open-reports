Queue a report export and collect its result

The host submits the same report request as a background job, checks its status, then downloads the completed file.

Host application · async render request
const accepted = await fetch(
  `${OPEN_REPORTS_URL}/api/v1/render/jobs`,
  {
    method: "POST",
    headers: { "content-type": "application/json" },
    body: JSON.stringify({
      report: statementReport,
      format: "pdf",
      data: { transactions: authorizedRows },
    }),
  },
);

const { jobId } = await accepted.json();
// Poll GET /api/v1/render/jobs/{jobId}
// Download GET /api/v1/render/jobs/{jobId}/output
This local sample has API authentication disabled. In production, keep the report data and any API key in your authenticated backend.
