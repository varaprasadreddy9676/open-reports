# Open Reports training coverage

This is an evidence-based map of the current in-app video shelf to product behavior. Product state is based on the user guide, API and embedding documentation, import notes, plugin/AI guides, the competitive-features status table, and the local demo runtime. It does not imply parity with JasperReports or Crystal Reports.

**State vocabulary:** *Shipped* means the capability exists in the current product. *Partial* means there are documented limits, configuration requirements, or missing workflow coverage. *Planned* means the project does not currently ship that capability. Video coverage is tracked separately; a capability may be shipped while its teaching still needs work.

## Capability audit

| Crosstabs | **Shipped** · `docs/design/competitive-features.md` | `crosstab-workflow`, `sales-crosstab` | The example compares Sum and Average; it does not imply arbitrary chart support. |
| Long reports, page breaks, page masters and break explanations | **Shipped** · `docs/USER_GUIDE.md` §4 | `long-report-pagination`, `page-master-variants`, `designer-tour` | A long cell continuing across pages needs a focused, verified example. | Logos, linked images, pre-printed stationery, QR/barcodes | **Shipped** · image property and printer output guides | `client-letterhead`, `hospital-letterhead`, `barcode-label-zpl`, `supermarket-receipt` | Linked resources must be reachable from the rendering server. The target printer still needs a physical scan/feed check. |
| Reusable library blocks | **Shipped** · `docs/USER_GUIDE.md` §6 | `reusable-blocks` | The lesson shows save/insert modes; version history, update and detach are available but deserve a deeper maintenance example. |
| Subreports and reusable child report files | **Shipped** · `docs/API.md` §Subreports | `shared-header-subreport` | The designer embeds the selected JSON definition. Independently managed host libraries must supply the child's definition and data; no server file-path lookup is implied. |
| PDF, HTML, DOCX, XLSX, CSV, ZPL and ESC/POS | **Shipped with format-specific limits** · renderer packages and `docs/API.md` | `output-formats`, `barcode-label-zpl`, `supermarket-receipt`, `sticker-sheet-workflow` | Output formats do not preserve identical layout or features. Verify every export and printer on its target device. |
| Save, validation, publish, immutable versions and visual comparison | **Shipped** · publish flow and version API | `publish-review`, `first-report` | Public demo storage may reset and is shared. Published template storage is optional when the host owns JSON. |
| Interactive viewer: parameters, find, bookmarks, sort, drill-down, drill-through and downloads | **Shipped** · `docs/EMBEDDING.md` | `interactive-viewer` | The lesson shows a published detail report; the host application still owns access control and row-level authorization. |
| Word import and conversion review | **Partial** · `docs/USER_GUIDE.md`, `docs/design/competitive-features.md` | `word-to-report` | The lesson reviews an import summary, conversion warnings, an editable draft and PDF output. Text, headings, embedded images, static tables and common page headers/footers convert; exact spacing, columns and floating elements need review. |
| JRXML single/folder import and issue review | **Partial** · `docs/JRXML_MIGRATION.md` | `jasper-folder-migration` | The lesson imports related JRXML into editable JSON drafts and checks linked files, migration notes and output. It does not produce `.jasper`; SQL is not run and Java/Groovy is not executed. Compare against a Jasper PDF made from the same input data before production use. |
| HTTP API, host-owned JSON, viewer/designer embedding and settings | **Shipped** · `docs/API.md`, `docs/EMBEDDING.md`, `docs/INTEGRATION_GUIDE.md` | `api-rendering`, `interactive-viewer`, `designer-embedding`, `settings-security` | Host mode returns edited JSON to the host callback. Instance-wide browser keys are visible to users; keep privileged keys and access control on the backend. |
| Async render jobs | **Shipped, in-memory queue** · `apps/server/src/jobs.ts`, `docs/API.md` | `async-render-jobs` | The queue and short-lived outputs are process-local and not a durable multi-instance job system. The lesson calls this out. |
| AI editing and MCP | **Shipped with external setup** · `docs/AI_AND_MCP.md` | No real proposal/acceptance walkthrough yet | Requires a user-supplied provider or local model and an MCP/API configuration. Do not fabricate an AI response. A real provider setup is needed before recording the edit loop. |
| Server plugins and plugin SDK | **Shipped, server-side and trusted-code only** · `docs/PLUGIN_DEVELOPMENT.md`, `packages/plugin-clinic-pack` | `plugin-workflow` | Demonstrated against a local server with the real clinic-pack plugin and custom text renderer. In this workspace, loading by bare package name failed; the built entry path worked. Plugins are not a sandbox or tenant authorization boundary. |
| Additional chart families and SSRS/RDL import | **Planned / not started** · `docs/design/competitive-features.md` | No training video | Do not market these as available or add instructional clips until product support ships. |
